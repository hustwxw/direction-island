# 方向小岛

适合小学一二年级孩子的中文前后左右互动训练。

## 使用方式

下载 `index.html`，双击或使用 Chrome、Edge、Safari 等浏览器打开即可。样式与游戏逻辑均集成在同一个 HTML 文件中，无需安装依赖或启动服务器。

## 游戏内容

- 我的左右手：先举真实的小手，再点击答案。
- 帮物品找家：将苹果放在指定位置。
- 小船向前开：根据船头朝向判断前后。
- 小伙伴的左右：根据人物朝向判断其自身左右。

每轮 6 题，提供三档难度、即时反馈、提示和练习统计。练习记录仅保存在当前浏览器。读题功能依赖浏览器的语音支持，离线时是否可用取决于设备语音资源。

建议每天练习 5—8 分钟，由家长陪同检查孩子的真实举手动作。
